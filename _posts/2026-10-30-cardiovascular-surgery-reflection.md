這篇記的是 10/19–10/30 的心外生活。因為不小心偷懶太久，又額外放了兩天假，所以乾脆一次集中寫完。

## 跟診：終於把課本裡的知識接上臨床

本身對心臟血管相關的知識算是挺有興趣。可惜這兩週直到最後才有機會跟診，但整體來說，我認為這次跟診非常有收穫！

### 1. 第一次真正看懂一點 Echo

剛進臨床大概兩個月，對於一些器材和檢查還不是那麼熟悉。跟之前比起來，現在已經比較會看 CT 和 X-ray 了，但在 Echo 的部分還是懵懵懂懂，平時也沒什麼機會實際看老師操作和診斷病人。

這次跟診看了好多病人做 Echo，也開始了解如何區分動脈與靜脈、判斷裡面有沒有血栓、確認硬化劑治療有沒有效果，以及觀察血管能不能被壓縮等等。這些對我來說，都是非常珍貴的經驗。

### 2. 靜脈疾病原來可以這樣處理

對於一些有下肢血栓或靜脈曲張的病人，我開始了解相關的處理方式，像是施打硬化劑，或利用雷射破壞部分淺層靜脈，包括大、小隱靜脈及更細小的分支。

這些都是進入臨床後實際去想，才會發現：「欸，原來真的可行欸！」的知識點。

### 3. 藥理背得出來，不代表知道臨床上怎麼用

以前讀書的時候，曾經稍微研究過一點 DOAC 的相關知識，像是藥物怎麼代謝等等；但我覺得自己當時忽略了一點，就是實際的臨床運用。

舉例來說，DVT 患者若要直接開始口服治療，可採用 apixaban 或 rivaroxaban；若使用 dabigatran 或 edoxaban，則需要先接受一段時間的 parenteral anticoagulation，例如 LMWH。

我覺得這也是進入臨床後感受非常深的地方。以前念書時，會覺得有些知識不重要，只背那些很明顯容易被拿來出考題的部分；實際進來之後，才發現有太多考試不太考的相關知識，反而才是跟患者息息相關的地方。實在是又上了一課。

### 4. 第一次遇到 Klippel–Trenaunay syndrome

今天遇到了一個相對少見的疾病：Klippel–Trenaunay syndrome（KTS）！查資料時也才知道，現代用語多半省略「Weber」，以避免和另一種高流量血管疾病 Parkes Weber syndrome 混淆。

患者的表現真的跟資料描述的三大特徵相符：

1. Port-wine stain：真的是葡萄酒色的斑。
2. 異常的靜脈曲張：單側膝周腫了很大一塊。
3. 肢體肥大：患側肢體明顯比另一側肥大。

另外，這類疾病與 PIK3CA pathway 的異常有關，因此部分嚴重患者甚至可能考慮 PI3K inhibitor 治療。

我相信今天這樣看過一次之後，下次再遇到一定會更加印象深刻。實際一點來說，說不定國考也有可能會考。

## 心外最重要的 Case report：Type A aortic dissection

這是我在晨會上報告的個案。

以前沒有去 ICU 探訪過病人，這次非常幸運，去的時候病患是清醒的，而且狀態還不錯，所以我能夠跟他進行簡單的病史詢問，也能觀察他本人的狀態。

除此之外，從小聽過很多主動脈剝離的情況，這卻是我第一次實際遇到 Type A dissection 的病人。因此，在花了蠻多時間研讀相關知識之後，不管是在醫學知識或倫理溝通上，都學到了非常多事情。

因為收穫點實在太多了，所以分類整理如下。

### 1. Aortic dissection 的分類、診斷與臨床表現

我更熟悉了 Stanford 與 DeBakey classification，也理解 Type A 與 Type B 的差異不只是剝離的位置，更會直接影響治療策略。

除此之外，我也學習到如何從胸痛延伸至背痛等臨床表現懷疑 aortic dissection，並透過 CTA 觀察 intimal flap、true lumen、false lumen，以及剝離延伸的範圍。

尤其是在 CT 影像上，看到 false lumen 過大而壓迫 true lumen，因而造成往下肢的血流減少，與病人的下肢麻木症狀相符。一開始我還一直很納悶，為什麼 true lumen 供應的地方血流反而會減少；後來才恍然大悟，確實可能因為受到 false lumen 壓迫而造成這種狀況。對我來說，想通這件事情算是又學到了一課。

另外，我也了解到在適當的臨床風險評估下，D-dimer 可以作為協助排除 aortic dissection 的工具，但不能單獨用來排除；以及 CXR、ECG 在急診評估中的角色。這些或許都會成為我將來在急診值班時，遇到類似 case 的養分。

### 2. 術前處置與 Guideline

在做 discussion 的時候，我閱讀了部分 2024 ESC、2024 EACTS/STS，以及 2022 ACC/AHA Guidelines，了解到 acute Type A dissection 的相關知識，包括：

1. 術前 anti-impulse therapy 的概念：利用 beta-blocker 控制心跳與血壓，減少 aortic wall stress，同時必須維持足夠的 organ perfusion。
2. 不同臨床分類與狀況所對應的處置方式。

值得一提的是，這位病人在確診後並非立即接受手術，也讓我開始思考 guideline recommendation 與實際臨床決策之間的差異，以及如何評估個別病人的手術風險與治療時機。

像這位病人，考量到進 ICU 後的狀況，以及他仍相當年輕，要做哪些手術、採用怎麼樣的手術，都需要經過非常謹慎的思考。畢竟他未來還有很長的人生，因此在相對穩定的狀況下，何時介入、如何介入，都是需要衡量的問題。

我想，這是我在這個 case 學習到很重要的一課。就像老師在晨會說的：永遠都要依照病人的狀況與條件去考量。

### 3. Total Arch Replacement 與 Frozen Elephant Trunk

這次手術時，我也有實際進刀房觀察。即使只是站在旁邊看，我確實也透過鏡頭和螢幕，更加了解 aortic arch replacement 的過程，以及如何重新連接 left common carotid artery、left subclavian artery 等重要分支。

我也了解了 Frozen Elephant Trunk（FET）與傳統 Elephant Trunk 的差異，以及 FET 如何同時處理 aortic arch 和 proximal descending aorta 的病變。

### 4. Malperfusion 與 True lumen／False lumen

這位病人的 dissection 範圍相當廣，甚至延伸到重要的腹部分支，讓我了解到 aortic dissection 不只是主動脈本身的問題，也可能影響腸道、腎臟及下肢等器官的血液供應。

我也了解到，即使完成 proximal aortic repair，遠端仍可能存在 residual dissection，因此需要持續評估器官灌流及後續影像變化。

### 5. 年輕患者與遺傳性主動脈疾病

這個病例讓我印象最深刻的其中一點，就是病人相當年輕，卻已經發生範圍如此廣泛的 aortic dissection。

原本對 connective tissue disease 的認識主要是 Marfan syndrome；但進一步查詢後，才知道還有 Loeys–Dietz syndrome、vascular Ehlers–Danlos syndrome，以及 ACTA2、MYLK、MYH11 等基因相關的 nonsyndromic heritable thoracic aortic disease（HTAD）。

雖然我也認為，臨床上要請每一個年輕的 dissection 病人接受基因檢測，在實行上確實有難度；但我同時也認為，基因是一個蠻有趣的切入點。說實話，我還蠻想更深入研究年輕 dissection 病人的遺傳議題，希望將來有機會可以去做這件事。

透過老師的說明，我也更加了解 nonsyndromic HTAD 確實沒有一些典型的「外觀症狀」；即使是 Loeys–Dietz syndrome、vascular Ehlers–Danlos syndrome，在台灣也不常見，或不容易被診斷出來。

因此，對於年輕的 aortic dissection 病人，除了處理疾病本身，如果現實條件允許，也可以將 genetic counseling 與未來家庭規劃納入考量。當然，感覺實行起來非常困難。

### 6. 術後追蹤與長期照護

我了解到，即使已經完成 Total Arch Replacement 和 FET，仍不能認為主動脈疾病已經完全解決。

術後需要持續追蹤 residual false lumen、aortic diameter、graft-related complications，以及遠端主動脈是否持續擴張。此外，長期血壓控制、規則服藥、定期 CTA 或其他影像檢查，對於降低後續併發症風險也相當重要。

## 整體心得

這次病例是我在心臟外科實習期間，花最多時間深入研究的病例之一。

從一開始對 aortic dissection 的理解主要停留在分類與緊急手術的概念，到後來逐漸能夠看懂 CTA，並了解 TTE、TEE、Total Arch Replacement 和 FET 的手術目的，也更能理解不同臨床決策背後需要考慮的因素。

另外，透過閱讀不同的 Guidelines，我也開始學習如何將文獻建議與實際病人情況進行比較，而不是只記住教科書上的治療方式。尤其是這位病人年紀較輕、剝離範圍廣泛，又可能存在 underlying genetic aortopathy，讓我了解到同樣是 Type A dissection，不同病人仍可能有不同的手術規劃與長期照護需求。

這次最大的收穫，是開始嘗試從一個臨床問題延伸出更多問題，再透過影像、手術紀錄和 Guideline 去尋找答案。

也讓我體會到，臨床學習不只是知道病人接受了什麼治療，更重要的是理解為什麼要這樣治療，以及後續還有哪些問題需要注意。

雖然做這個 case 的那天晚上幾乎沒有睡覺，但我覺得非常值得，因為真心學習到了好多知識，並且某種程度上也是在模擬將來成為外科醫師的生活！

另外也謝謝老師的指導。非常慶幸這次能有機會接觸這個 case，未來也會持續朝著成為一個外科醫師繼續努力。
